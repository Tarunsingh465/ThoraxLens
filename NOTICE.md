# Notices and visual credits

ThoraxLens is a separate PyTorch research implementation inspired by the workflow and explanatory structure of [Laurent Veyssier's Chest-X-Ray-Medical-Diagnosis-with-Deep-Learning repository](https://github.com/LaurentVeyssier/Chest-X-Ray-Medical-Diagnosis-with-Deep-Learning).

## Reference figures embedded in README

The DenseNet architecture figures and dense-connection animation referenced by the README are loaded from the original project’s public repository using their original raw GitHub URLs. They remain hosted by the upstream author, are identified as reference illustrations in the README, and are not ThoraxLens results:

- [DenseNet overview](https://github.com/LaurentVeyssier/Chest-X-Ray-Medical-Diagnosis-with-Deep-Learning/blob/main/asset/densenet.png)
- [Dense connection animation](https://github.com/LaurentVeyssier/Chest-X-Ray-Medical-Diagnosis-with-Deep-Learning/blob/main/asset/dense_connection.gif)

The custom SVG diagrams in `assets/` are ThoraxLens-specific explanatory graphics. The test AUROC chart is based on the project-reported held-out test metrics; the interpretability-flow illustration is explicitly conceptual and does not show an actual patient prediction.

## Dataset

The NIH ChestX-ray data are not included here. See the [NIH ChestX-ray portal](https://nihcc.app.box.com/v/Chestxray-NIHCC) and follow the dataset's current access terms.

## Clinical disclaimer

ThoraxLens is a research and educational prototype, not a medical device. It has not been clinically validated. Do not use it for diagnosis or care decisions.
