# Dataset access

The images are not included in this source bundle due to their large size. Download them directly from NIH:

https://nihcc.app.box.com/v/ChestXray-NIHCC

Required files: the 12 image archives (`images_001.tar.gz` … `images_012.tar.gz`) plus `Data_Entry_2017_v2020.csv`. Extract all images beneath `data/nih/images/` and put the CSV at `data/nih/Data_Entry_2017_v2020.csv`.

The dataset contains around 112,120 frontal-view images and requires tens of GB of storage. See the main README for the citation and limitations. Do not commit dataset archives, extracted images, or patient data to GitHub.
